RESTORE DATA

Pulihkan data dari file JSON backup. Proses ini akan mengganti data cloud saat ini.

Restore menimpa data aktif. Aplikasi akan mengunduh backup kondisi saat ini terlebih dahulu sebelum memulihkan file pilihan.

Panduan keamanan

  • Backup JSON hanya tersimpan di perangkat setelah diunduh; tidak dikirim ke Google Cloud Storage.
  • Lakukan backup sebelum restore atau perubahan besar.
  • Restore hanya tersedia untuk Admin dan membutuhkan konfirmasi tambahan.
  • Pastikan file backup berasal dari aplikasi ini dan isinya benar sebelum dipulihkan.
